# AttendX - Faculty User Guide

Welcome to AttendX! This guide will help you manage your classes, launch attendance sessions, and monitor student analytics.

## Launching an Attendance Session
To begin recording attendance for a class:
1. Navigate to **Attendance -> Create Session**.
2. Select your assigned **Subject** and **Class** (e.g. "Database Systems" for "CSE-A").
3. Select your verification method:
   - **QR Code Verification**: Generates a rotating cryptographic QR code for students to scan.
   - **Manual Override**: Allows you to simply call names and check boxes manually (useful for network outages).
4. Click **Start Session**.

## Using the QR Display
Once a QR session begins, project your screen to the class. The QR code on the screen will automatically change every 10 seconds. Students scanning an old code will be rejected by the server, drastically reducing proxy attendance via messaging apps.

## Monitoring Analytics
Navigate to **Analytics**. You can view aggregate data for your assigned classes.
- **Low Attendance Filter**: Instantly identify students hovering near the 75% danger zone.
- **Class Average**: Track the overall engagement trend of your classes across the semester.

## Generating Reports
If you need to submit attendance records to the administration:
1. Go to **Reports**.
2. Select the date range, class, and subject.
3. Click **Export PDF** for a professional document, or **Export CSV/Excel** if you wish to analyze the raw data in Excel.
